《行道》新手教程

十分钟看懂：你在干什么、一回合怎么走、血是怎么掉的、分是怎么算的。
适用版本 v1.3 + R01–R35 人数 2 / 3 / 4 / 6 / 8 一场 4 局 阅读时间 约 10 分钟

00先记住这四句话

《行道》的全部策略都长在这四条上。看懂它们，剩下的都是细节。

  1. 全场同时暗选，同时揭示。你出牌时不知道别人出什么，所以每一手都是在猜。
  2. 攻击数值只决定"打不打得中"，命中只扣 1 点血。用 14 阶打死你和用 2 阶打死你，掉的血一样多——贵的攻击不是为了多扣血，是为了保证命中。
  3. 攻击是全场范围的，不分方向。你砍出去的刀会落到所有挡不住的人头上，包括你的敌人、也包括没防的旁观者。
  4. 能量就是命。没有能量就出不了术，出不了术就只能白挨打。蓄力是唯一稳定的收入。
如果你只玩一局：目标就是活到最后。活到最后的人拿名次分、拿道牌、优先挑术集。一切花招都服务于"比别人活得久"。

01你要干什么：胜负与积分

一场 = 4 局

局血量上限道牌上限定位
第 1 局33重注局：全场只有基础术，数值差异小，3 点血意味着挨 3 下就死。靠判断力决胜。
第 2 局44开始出现封印 / 复制 / 反弹类术，多一次容错。
第 3 局5512 套术全开、道牌流通、装备流成形。
第 4 局 · 终局55同上，但本局积分 ×2——翻盘局。

每局开始时血量、能量、手牌全部重置（术集和总分带走）。所以第 1 局早死不等于整场报废。

一局怎么结束

打到只剩一个势力还有活人，那局就结束。若一直僵持，第 25 回合起每回合全场 −1 血，强制收敛。

积分怎么算

局末按势力排名（存活优先，其次存活回合数，都相同则随机），每势力的得分：

本局得分 = 势力数 − 名次 + (第一名 ? 2 : 0) + 本局击杀数
终局再 ×2
  • 第一名额外拿道牌：+1 张（终局 +2 张），发给该势力每名存活成员。
  • 术集在局末按存活长短轮流挑：活得越久越先挑（滚雪球），死得早的排后面； 存活时长相同的势力之间随机决定先后。每势力挑 1 套（见第 09 节）。
所以「苟」是有收益的，而且是三重收益。名次分第一名 +2、活得更久多拿一张道牌， 术集也是活得越久越先挑——分数、道牌、火力全都在奖励"活下来"。但击杀也有分， 而且你淘汰的人身上的能量会被瓜分。苟与杀的平衡，就是这游戏的核心张力。

02桌面上的东西

Web 版把玩家按势力分到牌桌四周：你在下方（南），同势力的人挨着你坐。1v1 正对、2v2 正对、2v2v2v2 各占一边、1v1v1 会空出一侧。

区域是什么
座位卡每个人的头像、血量条、能量、道牌数、身世、已夺到的术集、装备。公开术集和装备是明牌，对手能看到。
出牌槽座位卡前方，本回合打出的牌会在这里展示几秒（像斗地主的出牌区）。
中央天机坛本回合的天机名称与效果；有遗留的持续效果也会列在下面。点天机卡可以看全文。
底部手牌区你的术，按术系折叠（蓄力 / 攻击 / 防御 / 自爆 + 每个术集一组）。点组名展开或收起，再点具体的术选中。
右侧事件表逐回合记录：天机、谁出了什么、所有人的血量/能量变化。点右上角折叠，主画面会自动变宽。
看牌详情：电脑上鼠标悬浮任意牌/标签即可；手机上长按。想看天机全文、身世说明、术集内容，点一下会弹窗。

03三类牌：术 · 道牌 · 身世

术是每回合真正打出去的东西，分四类。开局全场只有 13 张基础术，术集要一局一局去挣。

蓄力
耗能 0
+1 能量。但本回合被命中就拿不到。是全场唯一的稳定收入，也是最大的破绽（阈值视为 0）。
攻术
耗能 1–30

耗能 0–1

自爆
耗能 0

阈值是"严格大于才算破"。数值 3 打阈值 3 → 挡住；数值 4 打阈值 3 → 破。装备「太虚护心镜」给你的防御数值 +0.5，就是为了把"刚好被打中"的那一刀卡成挡住——这是全作最精细的操作。

道牌（资源与装备）

33 种 / 60 张，分三类，靠局末奖励、拍卖、击杀瓜分等方式入手。每回合最多同时打出 1 张（和你的术一起暗选）。

  • 神装牌：拿到手就自动装载、立即生效。例如「太虚护心镜」（防御数值 +0.5）、「赤霄剑」（你的攻击 +1）、「罡风靴」（你的攻击翻倍）、「逆鳞金甲」（受伤反伤 0.5）。
  • 神通牌：即时生效。例如「回春」（回 2 血）、「引雷」（全场攻击 +3）、「终焉之奏」（全场血量变 1）。
  • 神策牌：要另开博弈画面或改写出牌本身。例如「囚徒」「狭路相逢」「偷天换日」「溯流光」。

术系是明牌，封禁也写在脸上（R59）

  • 所有术系一律公开（基础术除外）。包括官宦子弟局初临时借来的那一套——它在座位卡的术系行里带一个 *，状态栏还会单独标一条「临时术系·X」。没有"藏着掖着的术系"。
  • 「焚术」怎么用：先选一名敌方玩家，再看他本回合打出的那张术——
    • 他出的是基础术（三阶攻击、蓄力、普通防御……都算）→ 封掉这一张牌本身。其余阶攻击照常能打，但被烧掉的这一张本局全场都不能再用——基础术是公共牌，烧了就烧了。
    • 他出的是术系里的术 → 整整套术系被封，本局后续回合都不能再用。
  • 封禁不等于没收：术系还记在他名下（明牌），只是状态栏会标一条红色的「封禁·X」并划掉——所有人都能看到他被废了哪一块。

座位卡下面的「状态」面板

每张座位卡旁边都有一块独立的状态面板：东西两侧的玩家挂在卡片下方， 南北两排的玩家挂在卡片左右（和卡片同一水平线，不额外占一条横向高度）。 标题写着「状态」和条数，没状态时显示「无」——这样你扫一眼就知道谁身上干净、谁挂了东西。 状态行前面有一个小字标签：装（神装）/ 术（临时术系）/ 禁（封禁）/ 益（增益）/ 限（限制）/ 示（公示中）。 效果一结束就自动消失：

  • 神装（金色「装」）：已装载的装备名，点开看效果。
  • 封禁（红色「禁」）：被焚术封掉的术系 / 基础术，或被「失落的历史」封掉的上回合术牌。
  • 临时术系（土黄「术」）：官宦子弟抽来的那一套。
  • 减益 / 限制：装备失效（天命改易）、能耗 ×2（天灾）、仅可用基础术、被逼战、下回合术牌被封。
  • 增益 / 庇护：不扣血庇护（天下太平）、道牌公示（天下大白）、攻击 / 防御 / 蓄力加成、道牌免疫。

「天下大白」生效期间，座位卡会直接把那个人的道牌列出来——这是全场唯一能看见别人手牌的窗口。

神装怎么穿怎么脱（R55）

  • 获取即自动装载——不用额外动作，到手就生效。
  • 可以穿很多件，没有"2 个槽"的限制。
  • 但每件都计入道牌持有上限（= 血量上限）。穿得越多，能带的神通 / 神策就越少——这是神装的真正代价。
  • 卸下只能在出牌阶段做，卸下不消耗本回合的道牌名额。
  • 在出牌阶段装载，则要消耗本回合的道牌使用名额（等于本回合已经出过道牌了）。

手牌上限 = 血量上限，即第 1 局 3 张、第 3 局起 5 张。超了不会凭空消失——回合结束会进弃牌判断期，由你自己挑要弃哪几张。弃置发生在回合最末尾，是"这回合结束了"的标志。

身世（开场随机抽取，全程有效）

6 种，开场有抽身世动画，每人从这 6 种里随机拿到 1 种（可以重复，多人同一种是合法的）。 它决定你这整场的打法基调，且往往带来额外的操作时机：

身世效果要点
商贾之家从第 5 次蓄力起，蓄力效率 +1。长线积累
武林世家血量上限 +1。
官宦子弟第一 / 二 / 三局「开局」各一次：同时随机抽取本局争夺中的一个术系临时使用，不受 3 套上限约束。 纯随机、互不排斥——两个官宦子弟可能抽到同一套。抽完会公示 3 秒，让所有人看到谁拿到了哪套。
匠作之家选中术牌、未确认前可 +N 或 −N：付 N 能量加 N 数值，或降 N 数值换回 N 能量。超阶防御可再花 1 能量补掉"被普攻克"的缺点。
杏林世家出牌阶段可付 2 能量换一张治疗牌（回 1 血，可对任何人）。
平民子弟第 3 回合起可在出牌阶段做 1 血 ↔ 2 能量 的即时兑换： 点一次立刻生效一次，可反复点、来回换，血量不会低于 1 点。换完要重新选牌。 前两回合锁着——那时候大家都没能量，能换血等于白送 2 点启动资金。

红色四段是全部戏剧性的所在：你不知道别人出什么，然后同时亮牌，然后一起算账。 开场还有一段抽身世动画，每局开局官宦子弟会同时随机抽一次临时术系（公示 3 秒）——这两段只在局初走一次，不在上面的回合循环里。

决策阶段你能做什么

  1. 选 1 张术——从基础术 + 你势力拥有的术集里挑（手牌区按术系折叠，点组名展开）。
  2. 可选再带 1 张道牌——从手牌里选。
  3. 身世操作——和道牌挤在同一行（「天赋 · 身世名 ? [按钮]」），不再单独占一行。 想读天赋全文点那个 ?。点一次按钮就立刻生效一次，可以反复点（平民的血能兑换就是来回换）。 每次操作都会清掉你已经选好的术，逼你用新的血/能重新选——否则会出现"选好 4 费的牌、 再把能量换成血，结果付不起"的错位。
  4. 确认。确认后不可更改，所有人揭示后一起结算。

有倒计时的：决策 45 秒，超时自动出「普通防御」。能量不足时也一样——没能量可用的人只能出免费防御。

结算顺序（道牌按六档梯队插进去）

道牌不再是"谁先出谁先算"。每张道牌带一个 order（可以是小数），越小越优先。 整数部分是档位（①–⑥），小数部分是档内顺序——留小数是为了以后往中间插新牌不用重排整张表。

  1. 档 ① 改写出牌本身：溯流光 1.1（揭示后可以在能量上限内重出一次）→ 锁灵符 1.2 → 偷天换日 1.3。
  2. 档 ② 能量 / 血量直接变化：回春 2.1 → 献祭 2.2。
  3. 档 ③ 改本次出牌的数值：太虚护心镜 3.1（防御 +0.5）→ 赤霄剑 3.2 → 罡风靴 3.3 → 紫气玉佩 3.4 → 引雷 3.5（全场攻击 +3，等价于所有人防御 −3，且不提升任何人的防御阈值）→ 破防 3.6 → 倍蓄 3.7。
  4. 算所有攻击的最终数值（先加算、后乘算、再减守方修正），得出每个人的真实攻击值 / 防御值。
  5. 定胜者线 = 全场最高数值（自爆不算在内）。
  6. 御：攻击值 > 防御值才造成有效伤害，扣 1 血（相等算挡住；一回合基础伤害封顶 1 血）。
  7. 攻：低于胜者线的攻击者，判定失败各扣 1 血。但这 1 滴和上一步的「命中」共用同一个 1 血额度——出攻击的人防御恒为 0，必然已经在上一步被打了，所以正常情况下不会再扣第二次，日志里写「判定失败（已计入命中）」。
  8. 自爆：按自身血量扣血，使用者淘汰。
  9. 档 ④ 判定后才触发：聚灵玉环 4.1（有效伤害回能量）→ 洞玄冠 4.2（额外扣 0.5）→ 泣血珠 4.3（回 0.5 血）→ 逆鳞金甲 4.4（反伤 0.5）→ 替罪 4.9。替罪压在本档最后，把已经算出来的负面状态整包转移给别人。
  10. 被动效果（装备、身世触发）统一结算一轮。
  11. 档 ⑤ 另开博弈画面：收割 5.1 → 移魂术 5.2 → 囚徒 5.3 → 狭路相逢 5.4。
  12. 档 ⑥ 后续回合生效：往生咒 6.1 → 窃取 6.2 → 借刀杀人 6.3 → 焚术 6.4 → 终焉之奏 6.5 → 天下大白 6.6 → 窥天 6.7 → 天命轮转 6.8 → 枪打出头鸟 6.9 → 铁索连环 6.91。本回合不影响结算，但画面上会给出醒目提示。
  13. 被动（不占档位）：替身玉符（死亡即复活到 2 血）、无懈可击（道牌目标指向你 → 对你无效；缺了你那张牌就运作不了 → 整张彻底无效）。
  14. 淘汰者结算，能量被瓜分。
  15. 弃牌判断 / 弃置道牌：手牌超过血量上限的人自己挑牌弃掉。弃置在回合最末，是"这回合结束了"的标志。
三张牌这次改了：「太虚护心镜」从"受击数值 −0.5"改成 防御数值 +0.5；「倍蓄」明确 蓄力被打中则本回合一点能量都拿不到（未蓄力才改为 +1 能量）； 新增神策牌 「溯流光」——揭示后可以重新出一次牌，但消耗的能量必须 ≤ 你一开始出那张术的消耗，不能借机升档。
数值口径一句话：只有御术给防御；蓄力和攻击时防御都是 0（可被道牌 / 天机抬起来）。所以「同数值的人互不相伤」不是靠防御打平，而是靠胜者线并列跳过——并列最高的那一批人不参与受击判定。攻击 > 防御才算打中，相等算挡住。 术牌本身造成的基础扣血恒为 1——多人打中你也只掉 1 血，只有那张牌自带其他效果（额外扣半滴、扣能量、扣上限）才往上叠。

05血是怎么掉的：三个扣血来源

① 被命中 −1

你的阈值挡不住胜者线，就掉 1 点血。不管对方用的是 2 阶还是 14 阶。

而且一回合只掉这 1 点。哪怕三四个人同时够得到你、或者反弹也打中你，基础伤害都只结算一次；叠在上面的额外效果（增伤多扣半滴、吸你能量）才照常累加。所以「被围攻」可怕在附加效果和后续回合，不在一次翻倍。

② 判定失败 −1

你出了攻击，但数值低于全场最高——说明你这一手押错了，扣 1 点血。注意它会和「被命中」叠加：一个数值垫底的攻击者，既挨了胜者线的一刀，又吃了判定失败，一回合掉 2 点。第 1 局只有 3 血，这基本是致命的。

③ 自爆

唯一按数值扣血的例外，且需要你先把自己送走。

第 1 局只有 3 血：丁 一手就从 3 掉到 1，再挨一刀就出局。这就是"低数值攻击 + 不防御"的代价。

并列最高怎么办

如果多人打出了相同的最高数值，规则是：并列者之间互不相伤，但胜者线照常成立。

示例 · 甲、丁 都是「一阶普攻」(1)，丙 蓄力
人出牌数值结果
甲一阶普攻1并列最高 → 与丁互不相伤，不掉血
丁一阶普攻1同上，不掉血
丙蓄力阈 0阈值不够 → 被命中 −1
常见误解："并列 = 本次攻击全部作废，全场免伤"。不是。并列只保护并列者彼此；没防御、阈值低的人照样挨打。

06能量：你的生命线

初始 0 能量。所有术都要花能量（除了蓄力、普通防御、自爆）。收入来源：

来源说明
蓄力每次 +1。本回合被命中就拿不到——所以蓄力的人其实在裸奔。
补给第 10 / 15 / 20… 回合，全场 +1。
击杀瓜分有人被淘汰时，他身上的能量由造成过伤害者所在势力均分。
道牌 / 术效果例如「聚灵玉环」每次有效伤害回 1 能量。
平民子弟1 血 ↔ 2 能量即时兑换。可以反复换：先把血换成能量打一套大的， 或者反过来把能量补回血撑过这一回合。
新手最常见的死法：前几回合疯狂蓄力攒能量，然后一次性打一发大的——结果那发被人防御挡住，既没造成命中，也没吃到蓄力（被命中了），能量还全花光了。蓄力要在"大概率不会被命中"的时机蓄，比如场上多人出过防御、或你是唯一血量健康的人时。

07天机：每回合都可能改写局势

每回合先判天机：前三局 20%，终局期 30%；连续 5 回合没出，第 6 回合必出（保底）。24 种，效果五花八门——全场回血、全场掉血、攻击 +N、能量重分配、禁止防御……没触发就明写「天机平稳」。

  • 天机效果显示在中央天机坛，点开可以看全文；持续多回合的效果会一直列在下面，别忽略。
  • 部分天机需要当场表态（例如「天之赌场」——每人自选押多少能量，0 = 弃权，押最高者拿走一半，其余人平分另一半；「赊天」——见下面那条）。这类会弹出选择框，超时按保守值处理。
  • 「窥天」可以抢天机：本回合打出后挂起，下一次天机正式执行之前，你可以把这道天机某个人的那一份摘下来、挂到另一个人身上—— 被搬走的人完全不受影响，被嫁接的人吃到两份。
    全场类天机也能这样改：比如「焚天」全员 −1 血，把 A 那份挂到 B 身上之后，结果是 B 扣 2 血、A 扣 0 血、其余人各扣 1 血。这是窥天最狠的用法。
    落在一个具体人身上的天机（天罚、生死劫这类）则是直接换目标。全体状态改写类（阴阳倒转、命运乖离）和全场 buff 不能嫁接。
  • 「天命轮转」= 下回合必定动荡：打出后下一回合跳过概率判定，直接抽一张天机牌生效。因为它在本回合不影响任何事，所以看得见、也接得住。
「引雷」是新手杀手：它的效果是本回合所有攻击数值 +3，不提升任何人的防御阈值。也就是说原本挡得住的 3 / 4 级防御会被 5 / 7 破掉——而且打出引雷的人自己也要承担后果，你没自备防御就一样挨刀。「引雷 + 蓄力」是自杀式打法。

08拍卖：第 5 / 10 / 15… 回合

第 5 / 10 / 15… 回合开始时拍出一张道牌，是这些回合的第一个环节（不是第 6 回合开头）。

所有人用自己当前的能量出价，价高者得、只付自己的报价：

  • 只能按整点出价。上限 = 你当前能量向下取整（比如 3.5 点最多出 3 点），剩下不到 1 点的零头留在手里，出不了价。
  • 没拍到的人一分能量都不扣。流拍、出价低、并列出局、库存不足被挤掉——统统不付钱，只有真正拿到牌的人付款。
  • 它排在天机判定之前——先拍完再定天机。这个顺序是有意的：出价时你的能量还没被本回合的出牌花掉，买得起的东西比放在回合末更多。
  • 并列的处理和攻击完全不同：最高价并列且并列人数 ≥3 → 并列者各付各价、各得 1 张；两人同价或全场没人出价 → 流拍。
  • 第 5 回合和第 15 回合的购买力差异是设计的一部分——省能量不只是为了出术，也是为了抢牌。

09术集：越活越强的滚雪球

全场 12 套术（天马、游龙、兵将、山海、道士、北冥、明镜、太极、人道、妖道、鬼道、物道）。开局一套都没有， 每局末从本局争夺的那一批里挑 1 套，一个势力最多持有 3 套；重复或超上限则折算成 2 能量。

局末轮抽：活得越久越先挑

轮到谁看存活长短，不看名次分：

  • 活到最后 → 最先挑；出局越早 → 排得越后（死在第 3 回合的排在死在第 7 回合的后面）；
  • 存活时长完全相同的势力之间随机定先后（不按座位序，避免固定优势）；
  • 轮到你时中央会弹出轮抽卡：顺位、每家挑了什么、池子还剩哪几套；
  • 每家有 12 秒决定，超时自动随机挑一套（不会让你一个人卡住全场）。

谁替你挑？—— 由「最后被淘汰的人」决定

  • 2 人同盟里，两人的存活时长常常不同：由死得更晚的那位来挑（死得最晚 = 打得最好，也最了解战局）；
  • 两人同时被淘汰（存活回合数相同）→ 在他们之间随机挑一位当代表；
  • 不是代表的那位只能看着，不能替他决定（界面上会写"本局由队里最后被淘汰的 X 决定"）；
  • 多个势力同时被淘汰 → 这一批次内部随机决定谁先挑。

设计意图：术集是滚雪球资源，打得好的队应该更早拿到火力——"死得早"本身已经是结果， 再给它优先挑反而会削平差距。顺位将来还会综合击杀数、造成伤害、存活排序算权重，现在的"存活长度"只是简化版。

术集归势力所有、队内共享（2 人同盟共用同一批 3 套）。所以排名靠前不只是加分，更是拿到了下一局的火力——这就是"活到最后"滚雪球的方式。

术集风格
天马 / 游龙同构的攻防均衡套，都有 0 能量的免费盾。新手友好
兵将唯一没有 0 能量防御的套系；换来四阶及以上攻击耗能减半。进攻型
山海数值偏高；「山海有灵」是 ∞ 阈值，但最终数值 < 2 就能被破（一阶普攻专治）。
道士 / 北冥 / 明镜 / 太极特殊机制向：封印、复制、反弹、克隆。第 2 局起登场。
人道 / 妖道 / 鬼道 / 物道一/二/三阶递进的专线套系。

「赊天」怎么算（R75）

  • 会弹框：抽取到赊天时，每个存活玩家各收到一次赊借选择框，选项就是数字 0/1/2…， 0 表示不借。这是出牌之前的窗口（和天之赌场同一个阶段），有 12 秒，超时按 0（不借）处理。
  • 能借多少：额度 = 你拥有的道牌数（手上的道牌 + 已装载的神装，两者都算道牌）。 1 张道牌 = 1 点。一回合内道牌越多，能借的越多。
  • 淘汰时怎么清算（按顺序）： ① 先用你剩余的能量还；② 不够，每缺 1 点随机失去 1 张道牌（先手牌，再神装）； ③ 还不够就继续欠着——欠账跨局保留，之后你每次获得道牌（抽牌、拍卖）会被天道直接没收抵债。
    被债主先吃掉的那部分能量，击杀者就分不到了——所以借得多的人，被击杀时的"油水"可能很少。
  • 谁不用还：活到最后的那个人（胜利势力的存活成员）——局末豁免，一笔勾销。 但已经淘汰的队友照样要还：他们在倒下那一刻就已经清算过了，不会因为势力后来赢了而退回。
  • 没有"回合即将结束"的检查：借的时候不会预判你还要活多久。你可以在残局孤注一掷借满——赢了全免，输了拿命和牌还。

10同盟模式（2 人一势力）

房主可以设 2–4 个势力、每势力 1–2 人（合法人数 2/3/4/6/8）。同势力时：

  • 术集共享，局末每势力只挑 1 套，队内共用。
  • 积分共享，队友同分。
  • 存活 = 最后一名成员倒下才算势力灭亡，所以队友倒下不等于出局结束。
  • 击杀能量由造成伤害者所在势力的全体成员均分。
  • 攻击不会打到队友（同势力免伤）——唯一例外是「借刀杀人」造成的强制攻击，它对被强制者自己的队友照常生效。
  • 但「判定失败」不豁免队友：队友打出更高数值，同样会让你判定失败扣 1 血。配合失误是要付代价的。

11五个新手常踩的坑

坑真相
「我打 14 阶，能秒他」命中只扣 1 点血，跟数值无关。14 阶的意义是"保证破防"，代价是 14 能量。
「蓄力最安全」蓄力时没有防御、阈值视为 0，胜者线一旦成立你就是最软的目标，而且被命中还拿不到能量。
「出个小攻击试试水」低于最高值 → 判定失败 −1；同时你没防御 → 被命中 −1。小攻击经常是 −2。
「超阶防御 12，稳了」被 1 点的一阶普攻击破。同理「山海有灵」也被它破。
「并列了，这回合没事」只保护并列者。你没防御，照样挨刀。
